# 2027 CSO 全球可持续发展论坛 · 执行管理看板

保留上传项目的报表页面、方案资料和固定手机底部导航，支持受邀账号的在线协作。

## 使用边界

- 未登录仅返回上传方案原始资料：322项任务、59条公告、25项决策。协作新增和修改不对访客公开。
- 登录后读取共享数据库，支持任务、公告、决策的新增、全字段编辑、状态修改及二次确认删除。
- 表单扩展选项在线共享。模块、团队、里程碑仍为原方案的静态内容。
- 保存时记录修改人和时间；界面不展示用户内部标识。其他成员的更新每30秒拉取，也可手动刷新。
- 仅凭一次性邀请开通账号。管理员可生成7天有效的成员邀请码。初始管理员开通码不写入源码或公开构建产物。
- 密码加盐派生存储；会话使用安全、HttpOnly、SameSite Cookie；写入校验来源，并对登录尝试限流。

## 维护

- `npm run type:check`、`npm test`、`npm run build` 进行统一校验。
- `worker/schema.sql` 为幂等建表脚本；`node --experimental-strip-types scripts/prepare-data.mjs` 生成不覆盖现有资料的种子脚本。
- 数据库先初始化再发布；根目录 `wrangler.toml` 保持项目名称 `gxc1`，不配置域名或路由。
- `npm run deploy` 构建并发布。域名绑定由平台管理。
- `server`、`legacy` 保留上传项目的历史代码，不用于当前运行环境。
- `.deploy` 仅供维护，禁止复制到公开资源目录；历史下载包不代表当前发布状态。
